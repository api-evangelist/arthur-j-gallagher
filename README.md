# Arthur J. Gallagher (arthur-j-gallagher)

Arthur J. Gallagher & Co. is a global insurance brokerage, risk management, and consulting firm. Through its subsidiaries, the company offers developer APIs for security system integration and claims management.

## APIs

### Gallagher Command Centre REST API

REST API for integrating third-party systems with the Gallagher Command Centre security platform. Provides HTTP functions to query the Command Centre database for access control, alarm monitoring, cardholder management, and site management.

**Key capabilities:**

- **Cardholders** - Manage people and their access credentials
- **Alarms** - Monitor and manage security alarms
- **Access Groups** - Configure access control groups
- **Events** - Retrieve security events and audit logs

### Gallagher Bassett API

API for integrating with Gallagher Bassett claims management services. Gallagher Bassett is a global claims management provider and subsidiary of Arthur J. Gallagher, offering workers' compensation, general liability, and other claims services.
